# 2상태 칼만 추세 추정기 — 수학 명세

관측열 하나에서 세상의 변화 속도 $q$ 와 센서 잡음 분산 $R$ 을 분리 추정하고,
그 둘로 칼만 게인을 매 틱 결정하는 시스템의 전체 수식과 유도.
이 문서만으로 구현이 가능하도록 모든 식의 출처를 적었다.

구현: `kalman_trend.py`

---

## 1. 모델과 기호

숨은 값이 "가속도가 백색잡음"인 2상태 과정을 따른다고 가정한다.
기울기가 랜덤워크로 떠돌고, 수준은 그 기울기의 적분이다.

$$\dot{x}(t) = \nu(t), \qquad \dot{\nu}(t) = \sqrt{q}\,\xi(t), \qquad \mathbb{E}[\xi(t)\xi(t')] = \delta(t-t')$$

관측은 그 수준에 독립 잡음이 더해진 것이다.

$$z_k = x(t_k) + \varepsilon_k, \qquad \varepsilon_k \sim \mathcal{N}(0, R) \;\text{i.i.d.}$$

이산 상태벡터와 전이행렬:

$$\mathbf{x}_k = \begin{pmatrix} \ell_k \\ s_k \end{pmatrix}, \qquad
\mathbf{F}(\Delta t) = \begin{pmatrix} 1 & \Delta t \\ 0 & 1 \end{pmatrix}, \qquad
\mathbf{H} = \begin{pmatrix} 1 & 0 \end{pmatrix}$$

### 기호

| 기호 | 뜻 | 단위 |
|---|---|---|
| $z_k$ | 관측값 (ofi_norm) | $[z]$ |
| $x(t)$ | 숨은 진짜 수준 | $[z]$ |
| $\nu(t)$ | 숨은 진짜 기울기 | $[z]/$초 |
| $\ell_k$ | 필터의 수준 추정 (라인 `level`) | $[z]$ |
| $s_k$ | 필터의 기울기 추정 (라인 `slope`) | $[z]/$초 |
| $q$ | 가속도 잡음 세기 | $[z]^2/$초$^3$ |
| $R$ | 센서 잡음 분산 | $[z]^2$ |
| $\Delta t$ | 이번 틱 간격 (`recv_at` 차이) | 초 |
| $h$ | 2차 차분 목표 lag. **$\Delta t$ 와 다른 축** | 초 |
| $\mathbf{P}$ | 필터의 오차공분산 $2\times2$ | — |
| $v_k$ | innovation $= z_k - $ 예측 | $[z]$ |
| $S_k$ | 필터가 예상한 $v$ 의 분산 | $[z]^2$ |
| $k_0, k_1$ | 칼만 게인 두 성분 | 무차원, $1/$초 |
| $D$ | 세 점 조합 (수준·기울기 소거) | $[z]\cdot$초$^2$ |
| $W, G$ | $\text{Var}(D)$ 의 $R$ 계수, $q$ 계수 | 초$^4$, 초$^5$ |
| $A_h$ | lag $h$ 의 정규화 2차차분 분산 | $[z]^2$ |
| $f$ | $A_h$ 중 세상 몫의 비율 (라인 `world_frac`) | 무차원 |
| $th$ | 서프라이즈 임계 ($\chi^2_1$ 기준) | 무차원 |
| $\tau$ | 반감기에서 온 시간상수 $= $ 반감기$/\ln 2$ | 초 |

### 핵심 관계

$q$ 와 $R$ 은 **단위가 다른 별개의 양**이고, 둘의 비가 "관측을 얼마나 믿을지"를 정한다.
$\nu$ 는 관측 불가이며 어떤 계산에도 등장하지 않는다 — 추정기가 무엇을 재고 있는지 분석할 때만 쓴다.

**이 문서의 모든 추정은 $z$ 만 사용한다.** 필터 출력($\ell, s, \mathbf{P}$)이
$q$ 나 $R$ 의 추정으로 되돌아오지 않는다. 그래서 발산 고리가 없다.

> 검증: 같은 $z$ 에 $q$ 만 바꿔(= 필터만 바꿔) 돌리면 $\hat R$ 이 소수점까지 동일.
> 혁신 $v$ 로 게이트하던 버전은 $q = 0.1 / 1 / 10$ 에서 1.8761% 차이가 났다.

## 2. 프로세스 잡음 행렬 $\mathbf{Q}$ 유도

길이 $\Delta t$ 구간에서 상태에 새로 쌓이는 잡음은 **둘**이다.
가속도를 몇 번 적분하는지가 $\Delta t$ 의 지수를 결정한다.

$$b \equiv \nu(t_0{+}\Delta t) - \nu(t_0) = W(\Delta t) \qquad \text{(1번 적분)}$$

$$a \equiv x(t_0{+}\Delta t) - x(t_0) - \nu(t_0)\Delta t = \int_0^{\Delta t}\! W(u)\,du \qquad \text{(2번 적분)}$$

여기서 $W$ 는 세기 $q$ 의 브라운 운동이다.

$$\text{Var}\big(W(u)\big) = q\,u, \qquad \text{Cov}\big(W(u), W(w)\big) = q\min(u,w)$$

공분산에 $\min$ 이 나오는 이유: $u < w$ 이면 두 값은 시각 $u$ 까지의 경로를
공유하고, 그 이후 $W(w)$ 에 더해지는 부분은 $W(u)$ 와 독립이라 공분산에 기여하지 않는다.

### 세 원소 계산

기울기 잡음은 바로 나온다.

$$\text{Var}(b) = \text{Var}\big(W(\Delta t)\big) = q\,\Delta t$$

위치 잡음은 적분의 분산이고, 그것은 공분산의 이중적분이다.
$\min$ 이 있으니 적분 영역을 반으로 자르고 대칭이므로 두 배 한다.

$$\text{Var}(a) = \int_0^{\Delta t}\!\!\int_0^{\Delta t} q\min(u,w)\,du\,dw
= 2q\int_0^{\Delta t}\!\!\left(\int_0^{w}\! u\,du\right)\! dw
= 2q\int_0^{\Delta t}\!\frac{w^2}{2}\,dw
= \boxed{\frac{q\,\Delta t^3}{3}}$$

$a$ 와 $b$ 는 **같은 잡음**에서 나온 것이므로 상관이 있다.

$$\text{Cov}(a,b) = \int_0^{\Delta t}\! \text{Cov}\big(W(u), W(\Delta t)\big)\,du
= \int_0^{\Delta t}\! q\,u\,du = \boxed{\frac{q\,\Delta t^2}{2}}$$

### 행렬로 모으면

$$\mathbf{Q}(\Delta t) = \text{Cov}\begin{pmatrix} a \\ b \end{pmatrix}
= q\underbrace{\begin{pmatrix} \Delta t^3/3 & \Delta t^2/2 \\ \Delta t^2/2 & \Delta t \end{pmatrix}}_{\mathbf{M}(\Delta t)}$$

차수 3, 2, 1 은 가속도를 "2번 적분 / 한 번씩 / 1번 적분"한 것에 대응한다.
분모 3 과 2 는 위 이중적분과 단일적분의 결과다.

숫자 확인 ($q = 7.5\times10^{-4}$, $\Delta t = 0.1$초):

$$\mathbf{Q} = \begin{pmatrix} 2.50\times10^{-7} & 3.75\times10^{-6} \\ 3.75\times10^{-6} & 7.50\times10^{-5} \end{pmatrix}$$

### 주의 — $\mathbf{Q}$ 를 $R$ 에 비례시키면 게인에서 $R$ 이 약분된다

$\mathbf{Q} = q R\,\mathbf{M}$ 로 잡으면 $P \propto R$ 이 되어 게인 $P/(P+R)$ 에서
$R$ 이 완전히 약분된다. $R$ 을 고정해 리카티를 정상상태까지 돌린 게인
($\Delta t = 1$, $q = 1$):

| 고정 $R$ | $\mathbf{Q} = qR\mathbf{M}$ | $\mathbf{Q} = q\mathbf{M}$ (교과서) |
|---|---|---|
| $10^{-5}$ | 0.756738 | 0.985803 |
| $10^{-4}$ | 0.756738 | 0.918057 |
| $10^{-3}$ | 0.756738 | 0.756738 |
| $10^{-2}$ | 0.756738 | 0.548528 |
| $10^{-1}$ | 0.756738 | 0.360592 |

왼쪽 열이 전부 같다 — 센서가 만 배 시끄러워져도 똑같이 믿는 필터가 된다.
그래서 이 시스템은 $\mathbf{Q} = \hat q\,\mathbf{M}(\Delta t)$ 로 두고 $R$ 을 분리 추정한다.

## 3. 세 점 조합 $D$ — 수준과 기울기 소거

### 왜 1차 차분을 못 쓰나

1차 차분은 센서 잡음만 재지 않는다.

$$\Delta z = \underbrace{\big(x(t_k) - x(t_{k-1})\big)}_{\approx\, \nu\Delta t} + (\varepsilon_k - \varepsilon_{k-1})$$

$$\mathbb{E}\!\left[\frac{(\Delta z)^2}{2}\right] = R + \frac{\text{Var}(\Delta x)}{2}
\approx R + \frac{\Delta t^2\,\mathbb{E}[\nu^2]}{2}$$

둘째 항은 **그 순간의 기울기 제곱**이다. 그리고 $\nu$ 는 랜덤워크라
표준편차가 $\sqrt{q\,t}$ 로 자라므로, 시간이 지나면 이 항이 센서 몫을 집어삼킨다.
경로 400개 앙상블로 직접 잰 값:

| 경과 | $\sigma_\nu$ (실측) | 이론 $\sqrt{q t}$ | 기울기 몫 $\div\,2R$ |
|---|---|---|---|
| 10초 | 0.087 | 0.087 | 1.9% |
| 60초 | 0.207 | 0.212 | 9.8% |
| 300초 | 0.483 | 0.474 | 36.9% |
| 1000초 | 0.831 | 0.866 | 63.6% |
| 2000초 | 1.167 | 1.225 | 77.4% |

장 시작 10초엔 조건이 성립하고, 30분 뒤엔 성립하지 않는다.
예전 추정식은 1상태 모델($\text{Var}(\Delta x) = q_1\Delta t$, $\Delta t$ 의 1승)에서
온 것이고 그 경우는 실측 배율이 0.999 로 맞다. 2상태에서는 7.0배까지 벌어진다.

### 세 점에서 직선을 뺀다

세 점 $(t_0, z_0), (t_1, z_1), (t_2, z_2)$ 에 계수 $c$ 를 걸어 더해서
직선 성분을 죽이고 싶다.

$$D \equiv \sum_i c_i z_i$$

직선 항(상수항과 시간에 비례하는 항)이 둘 다 사라지도록 조건 둘이 필요하다.

$$\sum_i c_i = 0 \quad (\text{수준 } x_0 \text{ 소거}), \qquad
\sum_i c_i t_i = 0 \quad (\text{기울기 } \nu_0 \text{ 소거})$$

방정식 둘, 미지수 셋이므로 해는 상수배만큼 자유롭다.
$h_1 = t_1 - t_0$, $h_2 = t_2 - t_1$ 로 두면:

$$\boxed{\;c_0 = h_2, \qquad c_1 = -(h_1 + h_2), \qquad c_2 = h_1\;}$$

검산:

$$\sum c_i = h_2 - (h_1{+}h_2) + h_1 = 0$$

$$\sum c_i t_i = h_2 t_0 - (h_1{+}h_2) t_1 + h_1 t_2
= h_2(t_1{-}h_1) - (h_1{+}h_2)t_1 + h_1(t_1{+}h_2) = 0$$

등간격($h_1 = h_2 = h$)이면 $c = (h, -2h, h)$ 로 익숙한 $1, -2, 1$ 이 된다.

### 기하적 의미

양 끝을 이은 직선을 $t_1$ 에서 평가하면 $z_0 + (z_2{-}z_0)\,h_1/(h_1{+}h_2)$ 이다.
가운데 점이 그 직선에서 벗어난 거리에 $-(h_1{+}h_2)$ 를 곱하면 정확히 $D$ 다.

$$D = -(h_1{+}h_2)\left[\, z_1 - \left( z_0 + (z_2 - z_0)\frac{h_1}{h_1+h_2} \right) \right]$$

직선 = "수준 + 기울기" 이므로, 직선을 빼면 둘이 자동으로 빠진다.

### 왜 간격을 정확히 반영해야 하는가

등간격을 가정하고 $1, -2, 1$ 을 그대로 쓰면 소거가 어긋나
$\nu_0(h_2 - h_1)$ 항이 되살아난다. 기울기는 크게 떠돌아 있으니
그 누출이 실제 신호를 덮는다.

실측 (지수분포 틱, 중앙 0.069초, 최대 1.0초): 등간격을 가정하면
$\hat q$ 가 진짜의 **15.51배**. 위 일반형으로 바꾸면 정상으로 돌아온다.

**일반형은 등간격을 요구하지 않는다** — 위 조건 둘은 간격이 얼마든 정확히 성립한다.

## 4. 분산 분해 $\text{Var}(D) = qG + RW$

### 진짜 상태 부분

직선이 소거된 뒤 남는 것은 구간 안에서 새로 쌓인 잡음뿐이다.
두 구간의 잡음을 $(a_0, b_0)$, $(a_1, b_1)$ 로 두고 전개하면:

$$x_1 = x_0 + \nu_0 h_1 + a_0, \qquad \nu_1 = \nu_0 + b_0$$

$$x_2 = x_1 + \nu_1 h_2 + a_1 = x_0 + \nu_0 h_1 + a_0 + (\nu_0 {+} b_0) h_2 + a_1$$

여기에 $c = (h_2, -(h_1{+}h_2), h_1)$ 을 걸어 항을 모으면:

| 항 | $c_0 x_0$ | $c_1 x_1$ | $c_2 x_2$ | 합 |
|---|---|---|---|---|
| $x_0$ | $+h_2$ | $-(h_1{+}h_2)$ | $+h_1$ | **0** |
| $\nu_0$ | 0 | $-(h_1{+}h_2)h_1$ | $+h_1(h_1{+}h_2)$ | **0** |
| $a_0$ | 0 | $-(h_1{+}h_2)$ | $+h_1$ | $-h_2$ |
| $a_1$ | 0 | 0 | $+h_1$ | $+h_1$ |
| $b_0$ | 0 | 0 | $+h_1 h_2$ | $+h_1 h_2$ |

$$\boxed{\;D_x = -h_2\,a_0 + h_1\,a_1 + h_1 h_2\, b_0\;}$$

$x_0$ 와 $\nu_0$ 이 모두 사라진다. 분산을 재면 — $a_1$ 은 다른 구간의 잡음이므로
$(a_0, b_0)$ 와 독립이고, $a_0$ 와 $b_0$ 는 같은 구간이니 상관이 있다:

$$\begin{aligned}
\text{Var}(D_x)
&= h_2^2\text{Var}(a_0) + h_1^2\text{Var}(a_1) + h_1^2 h_2^2\text{Var}(b_0) - 2h_1 h_2^2\text{Cov}(a_0, b_0) \\
&= h_2^2\frac{q h_1^3}{3} + h_1^2\frac{q h_2^3}{3} + h_1^2 h_2^2\, q h_1 - 2h_1 h_2^2\frac{q h_1^2}{2} \\
&= q\left[\frac{h_1^3 h_2^2}{3} + \frac{h_1^2 h_2^3}{3} + h_1^3 h_2^2 - h_1^3 h_2^2\right] \\
&= \frac{q}{3}\,h_1^2 h_2^2 (h_1 + h_2)
\end{aligned}$$

2장의 $\text{Var}(a) = qh^3/3$, $\text{Var}(b) = qh$, $\text{Cov}(a,b) = qh^2/2$ 를
그대로 넣은 것이다. 셋째와 넷째 항이 정확히 상쇄된다.

### 센서 잡음 부분

$\varepsilon$ 은 서로 독립이므로 계수의 제곱을 더한다.

$$\text{Var}\!\left(\sum_i c_i \varepsilon_i\right) = R\sum_i c_i^2$$

### 합치면

$$\boxed{\;\text{Var}(D) = q\,G + R\,W\;}
\qquad G = \frac{h_1^2 h_2^2 (h_1 + h_2)}{3}, \qquad W = \sum_i c_i^2$$

### 등간격 환산 — 익숙한 식과 연결

$h_1 = h_2 = h$ 면 $c = (h, -2h, h)$ 이므로

$$W = h^2 + 4h^2 + h^2 = 6h^2, \qquad G = \frac{h^4 \cdot 2h}{3} = \frac{2}{3}h^5$$

그리고 $D = h(z_0 - 2z_1 + z_2)$ 이니 $\text{Var}(D) = h^2\,\text{Var}(\Delta^2 z)$ 이므로

$$\text{Var}(\Delta^2 z) = \frac{\text{Var}(D)}{h^2} = \frac{2}{3}q h^3 + 6R$$

### 정규화 — 이 시스템이 쓰는 표현

$W$ 로 나누면 $R$ 의 계수가 1 이 되어 바로 $R$ 추정치 꼴이 된다.

$$\boxed{\;s \equiv \frac{D^2}{W}, \qquad
A_h \equiv \mathbb{E}[s] = R + q\frac{G}{W} \;\overset{\text{등간격}}{=}\; R + \frac{q h^3}{9}\;}$$

($2/3 \div 6 = 1/9$ 에서 $h^3/9$ 가 나온다)

두 표기가 같은 식이라는 수치 확인:

| $h$ | $\frac23 qh^3{+}6R$ | $\text{Var}(D)/h^2$ | $\text{Var}(D)/W$ | $\text{Var}(\Delta^2 z)/6$ |
|---|---|---|---|---|
| 0.1 | 1.200050e-02 | 1.200050e-02 | 2.000083e-03 | 2.000083e-03 |
| 1.0 | 1.250000e-02 | 1.250000e-02 | 2.083333e-03 | 2.083333e-03 |
| 3.0 | 2.550000e-02 | 2.550000e-02 | 4.250000e-03 | 4.250000e-03 |

$W$ 로 나눈다는 것은 "$6R$ 의 6 을 미리 나눠둔다"는 뜻이고,
거기에 간격 불규칙을 더한 것이 일반형이다.

## 5. 두 lag 에서 $q$ 와 $R$ 분리

### 문제 — 식 하나에 미지수 둘

$$A_h = R + \frac{q h^3}{9} \qquad \leftarrow \text{1개의 식, 2개의 미지수}$$

lag 을 $2h$ 로 늘리면 $q$ 항이 8배로 커지고 $R$ 항은 그대로다 — 둘의 축이 갈라진다.

$$A_{2h} = R + \frac{q(2h)^3}{9} = R + \frac{8q h^3}{9}$$

### 소거 — $\hat q$

$$A_{2h} - A_h = \frac{8qh^3}{9} - \frac{qh^3}{9} = \frac{7qh^3}{9}$$

$$\boxed{\;\hat q = \frac{9\,(A_{2h} - A_h)}{7h^3}\;}$$

**이 식에 $\hat R$ 이 없다.** 이게 이 설계의 핵심이다.
lag 하나로 하면 $\hat q = 9(A_h - \hat R)/h^3$ 이라 $\hat R$ 이 과대추정되면
$\hat q$ 가 음수가 되고, $Q = 0 \to P \to 0 \to$ 게인 $\to 0$ 으로 필터가 얼어붙는다.

> 실측: 1차 차분 $\hat R$(진짜의 7배)을 넣으면 $\hat q = -2.13\times10^{-3}$
> (진짜 $+7.5\times10^{-4}$). 두 lag 의 차이를 쓰면 이 고리가 아예 끊긴다.

### 되대입 — $\hat R$

$$R = A_h - \frac{qh^3}{9} = A_h - \frac{1}{9}\cdot\frac{9(A_{2h}{-}A_h)}{7}
= A_h - \frac{A_{2h} - A_h}{7} = \frac{8A_h - A_{2h}}{7}$$

$$\boxed{\;\hat R = \frac{8A_h - A_{2h}}{7}\;}$$

기댓값이 정확히 $R$ 인 것 검산:

$$8A_h - A_{2h} = 8\!\left(R + \frac{qh^3}{9}\right) - \left(R + \frac{8qh^3}{9}\right)
= 8R + \frac{8qh^3}{9} - R - \frac{8qh^3}{9} = 7R$$

### 양수 조건

두 식 모두 뺄셈이므로 유한 표본에서 음수가 나올 수 있다.
세상비중 $f = (qh^3/9)/A_h$ 로 쓰면 여유(기댓값)가 정확히 대칭이다.

$$\hat q > 0 \iff A_{2h} - A_h > 0, \qquad \mathbb{E}[\,\cdot\,] = 7f \cdot A_h$$

$$\hat R > 0 \iff 8A_h - A_{2h} > 0, \qquad \mathbb{E}[\,\cdot\,] = 7(1{-}f) \cdot A_h$$

**$f$ 가 크면 $R$ 이 위험하고, $f$ 가 작으면 $q$ 가 위험하다.**
실측 음수율 (EMA 반감기 20초):

| $h/h^*$ | $f$ | $q$ 음수율 | $R$ 음수율 | $\hat R/R$ |
|---|---|---|---|---|
| 0.30 | 0.03 | **2.75%** | 0.00% | 1.00 |
| 0.50 | 0.11 | 0.22% | 0.00% | 1.00 |
| 1.00 | 0.50 | 0.00% | 0.45% | 0.94 |
| 2.00 | 0.89 | 0.36% | **34.78%** | 1.56 |
| 4.00 | 0.98 | 0.00% | **50.01%** | **11.95** |

음수를 하한으로 자르면 위쪽으로 편향되어 $f = 0.98$ 에서 $\hat R$ 이 12배로 터진다.

그리고 음수는 **EMA 가 거칠 때만** 나온다:

| $q$ 반감기 | $q$ 음수율 | $R$ 음수율 |
|---|---|---|
| 300초 | 0.00% | 0.00% |
| 60초 | 0.00% | 0.00% |
| 20초 | 0.00% | 0.45% |
| 5초 | 0.45% | 4.98% |
| 1초 | 10.00% | 15.89% |

**반감기 60초 이상이고 $h \approx h^*$ 면 음수가 아예 안 나온다.**
여기에 하한만 두면 된다 (10장).

## 6. lag 선택 — 세상비중 $f$ 와 기준 lag $h^*$

### 세상비중의 정의

$$f \equiv \frac{qh^3/9}{A_h} = \frac{qh^3/9}{R + qh^3/9}
\qquad\Longleftrightarrow\qquad R = (1-f)A_h$$

추정값에서 바로 나오므로 `world_frac` 라인으로 내보낸다.

$$\hat f = 1 - \frac{\hat R}{A_h}$$

### 세상 몫과 센서 몫이 같아지는 lag

$$\frac{qh^3}{9} = R \quad\Longrightarrow\quad \boxed{\;h^* = \left(\frac{9R}{q}\right)^{1/3}\;}$$

$q = 7.5\times10^{-4}$, $R = 2.0\times10^{-3}$ 이면 $h^* = 2.88$초, 그때 $f = 0.50$.

### $h$ 에 따라 구도가 뒤바뀐다

세상 몫은 $h^3$ 에 비례하고 센서 몫은 $h$ 에 무관하다.

| $h$ | 세상 몫 | 센서 몫 | $f$ | 뽑을 수 있는 것 |
|---|---|---|---|---|
| 0.1초 (틱) | 8.33e-08 | 2.0e-03 | **0.004%** | $R$ |
| 0.5초 | 1.04e-05 | 2.0e-03 | 0.52% | $R$ |
| 1.0초 | 8.33e-05 | 2.0e-03 | 4.0% | — |
| **2.88초** | 2.00e-03 | 2.0e-03 | **50.0%** | $q$ |
| 6.0초 | 1.80e-02 | 2.0e-03 | 90.0% | $q$ |

**틱 간격에서는 세상 몫이 0.004% 라 $q$ 를 뽑을 수 없고, 거꾸로 그 몫을
무시해도 $R$ 은 정확하다.** 그래서 두 lag 을 쓴다.

### 오차 증폭

뺄셈으로 작은 수를 얻으면 상대오차가 증폭된다. 증폭률은 목표 항의 비중의 역수다.

$$\frac{\delta\hat q}{\hat q} = \frac{1}{f}\cdot\frac{\delta A}{A},
\qquad
\frac{\delta\hat R}{\hat R} = \frac{1}{1-f}\cdot\frac{\delta A}{A}$$

$f = 0.5$ 에서 양쪽 모두 2배로 가장 균형이 좋다.
$f = 0.11$ 이면 $q$ 쪽이 9배, $f = 0.89$ 이면 $R$ 쪽이 9배 증폭된다.

### 실측 — $\hat q$ 의 흔들림이 $h^*$ 에서 최소

증폭률만 보면 $h$ 가 길수록 좋지만, $h$ 가 길면 삼중항의 유효 독립 표본이
줄어든다. 두 효과가 상충해 최적점이 $h^*$ 근방에 생긴다.

| $h/h^*$ | $f$ | $\hat q/q$ | $\hat q$ 의 CV |
|---|---|---|---|
| 0.35 | 0.041 | 0.84 | 0.752 |
| 0.50 | 0.111 | 0.87 | 0.421 |
| 0.70 | 0.255 | 0.93 | 0.242 |
| **1.00** | **0.500** | 0.93 | **0.232** |
| 1.50 | 0.771 | 0.96 | 0.266 |
| 2.00 | 0.889 | 0.98 | 0.303 |
| 5.00 | 0.992 | 1.07 | 0.439 |

CV = 표준편차 $\div$ 평균. $\hat q/q$ = 추정 평균 $\div$ 진짜 $q$.

### 설정 지침

$h$ 는 고정 파라미터다. 하루치 기록에서 `world_frac` 을 보고 한 번 맞춘다.

| `world_frac` | 뜻 | 조치 |
|---|---|---|
| 0.5 근처 | $h \approx h^*$. 잡음 최소 지점 | 그대로 |
| 0.1 이하 | $h$ 가 너무 짧다. $q$ 쪽 증폭 9배 이상 | `dd_lag` 늘린다 |
| 0.9 이상 | $h$ 가 너무 길다. $R$ 쪽 증폭 9배 이상 | `dd_lag` 줄인다 |

## 7. 칼만 필터 재귀

### 예측

$$\mathbf{x}^- = \mathbf{F}(\Delta t)\,\mathbf{x},
\qquad
\mathbf{P}^- = \mathbf{F}\mathbf{P}\mathbf{F}^\top + \hat q\,\mathbf{M}(\Delta t)$$

$2\times2$ 를 전개하면 (대칭이므로 세 성분):

$$\begin{aligned}
\ell^- &= \ell + s\,\Delta t \\
s^- &= s \\[4pt]
P^-_{00} &= P_{00} + 2\Delta t\,P_{01} + \Delta t^2 P_{11} + \hat q\,\Delta t^3/3 \\
P^-_{01} &= P_{01} + \Delta t\,P_{11} + \hat q\,\Delta t^2/2 \\
P^-_{11} &= P_{11} + \hat q\,\Delta t
\end{aligned}$$

### 혁신

$$v = z - \ell^-, \qquad S = P^-_{00} + \hat R$$

($\mathbf{H} = (1\;0)$ 이라 $\mathbf{H}\mathbf{P}^-\mathbf{H}^\top = P^-_{00}$ 로 스칼라)

### 게인

$$\mathbf{K} = \mathbf{P}^-\mathbf{H}^\top S^{-1}
\quad\Longrightarrow\quad
k_0 = \frac{P^-_{00}}{S}, \qquad k_1 = \frac{P^-_{01}}{S}$$

### 갱신

$$\mathbf{x} = \mathbf{x}^- + \mathbf{K}v
\quad\Longrightarrow\quad
\ell = \ell^- + k_0 v, \qquad s = s^- + k_1 v$$

$$\mathbf{P} = \mathbf{P}^- - \mathbf{K}\mathbf{H}\mathbf{P}^-
\quad\Longrightarrow\quad
\begin{aligned}
P_{00} &= (1-k_0)P^-_{00} \\
P_{01} &= (1-k_0)P^-_{01} \\
P_{11} &= P^-_{11} - k_1 P^-_{01}
\end{aligned}$$

### 출력

$$\texttt{level} = \ell, \qquad \texttt{slope} = s,
\qquad \texttt{lead} = \ell + s\cdot\tau_{\text{lead}}$$

`lead` 는 외삽이다. $\tau_{\text{lead}}$ 를 키우면 지연이 줄지만
전환점에서 오버슈트한다 — 눈으로 "빨라 보인다"로 고르지 말고 IC 로 확인할 것.

### 초기화

$$\ell \leftarrow z_0, \quad s \leftarrow 0, \quad
P_{00} = P_{11} = \hat R \times 10^6, \quad P_{01} = 0$$

$P$ 를 크게 잡아 초반에는 관측을 거의 그대로 받는다.

## 8. 추정기 갱신식

### 시간 기반 지수평균

틱 간격이 불규칙하므로 고정 $\alpha$ 를 쓰면 안 된다.
**반감기를 못박는다**: $\Delta t$ 가 지나면 옛 값의 비중이 $(1-k)$ 배이고,
그게 반감기 $T$ 후 $1/2$ 이어야 하므로

$$(1-k) = 2^{-\Delta t/T} = e^{-\Delta t \ln 2 / T}
\quad\Longrightarrow\quad
k = 1 - \exp\!\left(-\frac{\Delta t \ln 2}{T}\right)$$

$\tau \equiv T/\ln 2$ 로 미리 나눠두면 $k = 1 - e^{-\Delta t/\tau}$.

| $T$ | $\Delta t$ | $k$ |
|---|---|---|
| 60초 | 0.1초 | 0.001155 |
| 60초 | 1.0초 | 0.011486 |
| 1800초 | 0.1초 | 0.000039 |
| 1800초 | 1.0초 | 0.000385 |

### 창 키우기 — 워밍업 문제의 해답

$$\boxed{\;k = \max\!\left(\frac{1}{n},\;\; 1 - e^{-\Delta t/\tau}\right)\;}$$

$n$ = 그 EMA 가 받은 표본 수. $n{=}1 \to k{=}1$, $n{=}2 \to k{=}0.5$ (두 표본의
정확한 평균), … 초반에는 "지금까지 받은 전부의 정확한 평균"이고,
$1/n < k_\tau$ 가 되면 EMA 로 자동 전환된다.

**이게 없으면 긴 반감기를 못 쓴다.** 시드의 남은 가중치가 $2^{-t/T}$ 이므로
반감기 30분이면 30분 뒤에도 추정치의 **절반이 시드**다.

$\hat R/R$ 궤적 (반감기 1800초 고정, 시드 방식만 변경):

| 경과 | 단일표본 시드 | 첫 200개 평균 | 창 키우기 |
|---|---|---|---|
| 5분 | 3.42 | 1.29 | 1.09 |
| 30분 | **2.52** | 1.19 | **1.04** |
| 60분 | 1.83 | 1.09 | 1.01 |
| 120분 | 1.22 | 1.01 | 0.98 |

난수만 바꿔 세 번 돌린 30분 시점 값:

| 시드 방식 | 결과 |
|---|---|
| 단일표본 | **[4.06, −0.01, 3.52]** ← 운에 좌우 |
| 첫 200개 평균 | [1.26, 0.96, 1.36] |
| 창 키우기 | [1.06, 0.99, 1.07] |

$-0.01$ 이 나오면 $\hat R \approx 0$ 이라 게인이 1 에 붙어 관측을 그대로
복사한다 (예전 `obs_var=0` 버그와 같은 구멍).

### 두 반감기 — $q$ 와 $R$ 의 분리 수단

**수렴 후 치우침은 반감기와 무관하다** (전부 1.006~1.009).
반감기가 바꾸는 건 흔들림뿐:

| 반감기 | 수렴 후 $\hat R/R$ | 수렴 후 CV |
|---|---|---|
| 60초 | 1.006 | 0.159 |
| 600초 | 1.009 | 0.025 |
| 1800초 | 1.008 | 0.008 |

$R$ 은 진짜로 상수이므로 긴 평균이 올바른 추정기다.
$q$ 는 변해야 하므로 짧게 둔다.

| | 반감기 | 게이트 | 쓰는 쌍 |
|---|---|---|---|
| $\hat q$ | **60초** | 안 씀 (사건을 봐야 함) | $A^{\text{fast}}_h$, $A^{\text{fast}}_{2h}$ |
| $\hat R$ | **1800초** | 적용 (이상치 제거) | $A^{\text{slow}}_h$, $A^{\text{slow}}_{2h}$ |

### 최종 추정식

$$\boxed{\;\hat q = \max\!\left(\frac{9(A^{\text{fast}}_{2h} - A^{\text{fast}}_h)}{7h^3},\;\; q_{\min}\right)\;}$$

$$\boxed{\;\hat R = \max\!\left(\frac{8A^{\text{slow}}_h - A^{\text{slow}}_{2h}}{7},\;\; A^{\text{slow}}_h \cdot \rho_R\right)\;}$$

하한은 10장.

### 결과 — 설계 목표의 검증

$q$ 가 10배로 뛰는 구간:

| 구간 | $\hat q/q$ | $\hat R/R$ | 게인 $k_0$ | nis |
|---|---|---|---|---|
| 전반 | 0.92 | 1.03 | 0.1469 | 0.963 |
| **중간 ($q{\times}10$)** | **1.00** | **1.21** | **0.2199** | 0.853 |
| 후반 | 0.95 | 1.03 | 0.1484 | 0.982 |

**게인이 1.50배 올라간다.** $\hat q$ 가 10배를 정확히 잡고 $\hat R$ 은 유지된다.

## 9. 서프라이즈 게이트

### 표본의 분포

평상시 $D \sim \mathcal{N}(0,\, W R)$ 이므로

$$\frac{s}{A} = \frac{D^2}{W A} \sim \chi^2_1$$

**이게 게이트 전체의 근거다.** 가우시안의 제곱을 자기 평균으로 나눈 값이면
자유도 1 카이제곱이고, 아래 모든 상수가 거기서 나온다.

### 판정식

$$\boxed{\;\frac{s}{A^{\text{slow}}} > th \;\Longrightarrow\; \text{제외}\;}$$

건당 발화 확률은 $\chi^2_1$ 의 꼬리다. $\chi^2_1 = Z^2$ 이므로

$$p(th) = P(\chi^2_1 > th) = P(|Z| > \sqrt{th}) = \text{erfc}\!\left(\sqrt{th/2}\right)$$

(scipy 없이 `math.erfc` 로 정확히 계산된다 — scipy 와 $10^{-17}$ 까지 일치)

### 절단편향 보정 $c(th)$

$\chi^2_1$ 의 평균은 정확히 1 이다. 그런데 $th$ 넘는 꼬리를 버리면
남은 것들의 평균은 1 보다 작다. 그래서 $\hat R$ 이 체계적으로 작아진다.

$$c(th) \equiv \mathbb{E}\big[\chi^2_1 \mid \chi^2_1 < th\big]$$

$\int z^2\varphi(z)dz = \Phi(z) - z\varphi(z)$ 를 $[-a, a]$ ($a = \sqrt{th}$) 에서
평가하면

$$\mathbb{E}\big[Z^2 \mathbb{1}\{|Z|<a\}\big] = (1-p) - 2a\varphi(a)$$

이를 $P(|Z| < a) = 1-p$ 로 나누면

$$\boxed{\;c(th) = 1 - \frac{2\sqrt{th}\,\varphi(\sqrt{th})}{1-p(th)}\;}$$

| $th$ | $p(th)$ | $c(th)$ | 꼬리가 들고간 평균 몫 |
|---|---|---|---|
| 3 | 8.326% | 0.6636 | **33.6%** |
| 5 | 2.535% | 0.8497 | 15.0% |
| 6.63 | 1.003% | 0.9246 | 7.5% |
| **9** | **0.270%** | **0.9733** | **2.7%** |
| 10.83 | 0.100% | 0.9883 | 1.2% |
| 15 | 0.011% | 0.9983 | 0.2% |

$th = 3$ 을 쓰면 표본의 8.3% 만 버리는데 평균의 33.6% 가 날아간다.
$\chi^2_1$ 꼬리가 그만큼 두껍다.

### 갱신식 (보정 포함)

$$A^{\text{slow}} \leftarrow
\begin{cases}
\dfrac{s}{c(th)}\,k + A^{\text{slow}}(1-k) & s/A^{\text{slow}} \le th \\[8pt]
A^{\text{slow}} \text{ (그대로)} & s/A^{\text{slow}} > th
\end{cases}$$

### 자기참조 — $th > 2$ 조건

$s$ 를 $A^{\text{slow}}$ 로 재는데 $s$ 가 $A^{\text{slow}}$ 를 갱신한다.
0 근방의 사상을 전개하면, $s$ 의 밀도가 0 에서 양수일 때
$\mathbb{E}[s \mid s < a] \approx a/2$ 이므로

$$\frac{dT}{dA}\bigg|_{A \to 0} = (1-k) + k\cdot\frac{th}{2}$$

$$\boxed{\;th > 2 \;\Rightarrow\; 0 \text{ 이 불안정(탈출)}, \qquad th < 2 \;\Rightarrow\; 0 \text{ 이 흡수}\;}$$

실측 수렴값: $th{=}1.0 \to 0$, $th{=}1.5 \to 0$, $th{=}2.0 \to$ 경계,
$th{=}3.0 \to 0.716$, $th{=}9 \to 0.999$.

**단 $s$ 에 0 에서의 원자(중복 스냅샷)가 있으면** $\mathbb{E}[s|s<a] = O(a^2)$ 가 되어
$th$ 와 무관하게 0 이 국소 흡수점이 된다. 그래서 중복을 먼저 버린다 (10장).

### 포아송 집계

창 $W_{\text{p}}$ 초 안의 발화 수 $N$ 을 포아송으로 평가한다.

$$\hat\lambda = p(th)\cdot \hat r \cdot W_{\text{p}}, \qquad
\hat r = \text{EMA}(1/\Delta t) \;\text{(틱 밀도)}$$

$$P(N \ge n) = 1 - \sum_{i=0}^{n-1}\frac{e^{-\hat\lambda}\hat\lambda^i}{i!}$$

($n$ 항만 더하면 되므로 라이브러리가 필요 없다)

**$\hat\lambda$ 를 실제 발화율의 EMA 로 추정하면 안 된다.** 활발한 구간이
길어지면 $\hat\lambda$ 가 올라가 경보 기준도 같이 올라간다 — 스스로 둔감해진다.
실측: 발화율 EMA 로 잡으면 0.4714, 이론값 $p\cdot W_{\text{p}}$ 는 0.0540 (8.7배).

**$p$ 값 자체는 믿지 말 것.** 사건이 군집하므로 실측이 포아송보다 꼬리가 두껍다:

| 창 안 발화 수 | 실측 | 포아송 | 배율 |
|---|---|---|---|
| $\ge 1$ | 8.27% | 37.59% | 0.2× |
| $\ge 3$ | 1.19% | 1.23% | 1.0× |
| $\ge 4$ | 0.90% | 0.14% | **6.3×** |

임계 개수를 고르는 자릿수 도구로만 쓴다.

### 게이트가 하는 일과 하지 않는 일

**하는 일 — 이상치 제거.** $\hat R/R$, 이상치 = 틱 하나의 센서잡음이 8배로 튀는 사건:

| 이상치 | 60초 게이트✗ | 60초 게이트✓ | 1800초 게이트✗ | 1800초 게이트✓ |
|---|---|---|---|---|
| 0% | 0.95 | 0.94 | 0.93 | 0.87 |
| 1% | 1.49 | 0.99 | 1.37 | 0.89 |
| 3% | 2.83 | 1.11 | **2.37** | **0.95** |
| 10% | 7.14 | 2.07 | 5.93 | 1.22 |

**반감기로는 대체되지 않는다.** 30배 늘려도 3% 에서 2.83 → 2.37 뿐이다.
평균은 큰 값에 끌려가고, $8\sigma$ 이상치는 제곱하면 64배라 3% 가 평균의 66% 를
차지한다 ($0.03 \times 64 + 0.97 \times 1 = 2.89$). 반감기는 흔들림을 줄이고
편향은 못 줄인다.

**하지 않는 일 — 사건 구간 보호.** 제외율 측정:

| $th$ | 평시 | 사건 시작 60초 | 사건 전체 |
|---|---|---|---|
| 9.0 | 0.24% | **9.00%** | **0.27%** |
| 3.0 | 7.09% | 21.50% | 4.59% |
| 1.5 | 16.55% | 32.50% | 9.25% |

게이트는 **꺾이는 순간만** 잡는다. 사건이 지속되면 $A$ 도 따라 올라가
$s/A$ 가 1 로 돌아온다 — "평소보다 크다"를 재는 기계라 그 '평소'가
올라가면 눈이 먼다. 사건 구간 보호는 5장의 뺄셈이 대수적으로 담당한다.

### 과다제외 가드

센서 특성이 영구히 바뀌면 전부 제외되어 $A^{\text{slow}}$ 가 갇힌다.
최근 $n_g$ 표본의 제외 비율이 상한을 넘으면 제외를 해제한다.

실측: $\hat R$ 을 진짜의 1/100 에서 출발시켰을 때
가드 없음 → 회복 2시간, 가드 0.5 → 30분.

## 10. 진단과 안전장치

### nis — 유일한 자기진단 창

$$\text{nis} \equiv \frac{v^2}{S}, \qquad
\overline{\text{nis}} = \text{EMA}(\text{nis}) \approx 1 \;\text{이어야 한다}$$

$\hat q = q$, $\hat R = R$ 이면 $M = P$ 이고 $V = S$ 이므로 $\text{nis} = 1$.
이게 일관성 조건이다.

### 정리 A — $P$ 는 약속이지 측정이 아니다

1상태로 줄여 손으로 풀면 정상상태가 닫힌 식으로 나온다.

$$P = \frac{P\hat R}{P + \hat R} + \hat Q
\;\Longrightarrow\;
P^2 - \hat Q P - \hat Q \hat R = 0
\;\Longrightarrow\;
P = \frac{\hat Q + \sqrt{\hat Q^2 + 4\hat Q\hat R}}{2}$$

$$k_0 = \frac{P}{P + \hat R}$$

진짜 예측오차는 오차 재귀 $e_{t+1} = (1-k_0)e_t - k_0\varepsilon_t + w_t$ 에서

$$M = (1-k_0)^2 M + k_0^2 R + Q
\;\Longrightarrow\;
M = \frac{k_0^2 R + Q}{k_0(2 - k_0)}$$

$\hat Q = \alpha Q$ 로 과소추정하면 ($Q = R = \hat R = 1$):

| $\alpha$ | $P$ (필터 주장) | $M$ (진짜 오차) | $M/P$ | nis |
|---|---|---|---|---|
| 1 | 1.618 | 1.618 | 1.0 | **1.000** |
| $10^{-1}$ | 0.370 | 2.296 | 6.2 | 2.406 |
| $10^{-2}$ | 0.105 | 5.569 | 53.0 | 5.944 |
| $10^{-4}$ | 0.0100 | 50.51 | **5,026** | 50.99 |
| $10^{-6}$ | 0.0010 | 500.5 | **500,251** | 501.0 |

점근적으로 $k_0 \approx \sqrt\alpha$, $M \approx \frac{1}{2\sqrt\alpha}$ 이므로

$$\frac{M}{P} \approx \frac{1}{2\alpha}, \qquad \text{nis} \approx \frac{1}{2\sqrt\alpha}$$

$P \to 0$ (점점 확신) 하면서 $M \to \infty$ (점점 틀림) — **반대 방향으로 벌어진다.**

**핵심: $P$ 의 리카티 재귀에 $z$ 가 한 글자도 없다.** $P$ 는 데이터를 보지 않고
$\hat q, \hat R$ 만으로 굴러가므로 자기가 틀렸다는 걸 구조적으로 알 수 없다.
$v^2/S$ 만이 "예측과 측정이 맞는가"를 비교하는 유일한 양이다.

### $\hat q$ 하한

과소추정은 치명적이고 과대추정은 시끄러울 뿐이다. 비대칭이 분명하므로 하한을 둔다.
세상/센서 50:50 지점이 $q = 9R/h^3$ 이므로 그 값의 일정 비율로 잡는다.

$$\boxed{\;q_{\min} = \rho_q \cdot \frac{9\hat R}{h^3}, \qquad \rho_q = 10^{-2}\;}$$

**측정값($\hat R$, $h$)에서 만든다.** $\hat q$ 자신 기준으로 두면 승법 래칫이 생긴다
(옛 25배 클램프 사고).

좋은 소식 — 게인은 $q$ 의 1/4승이라 $\hat q$ 가 꽤 틀려도 게인은 덜 틀린다:

| $q$ 오차 | 게인 오차 |
|---|---|
| −75% | −23.6% |
| −50% | −12.3% |
| +100% | +13.3% |
| +300% | +27.3% |

$\hat q$ 의 CV 0.23 은 게인으로는 5.4% 다.

### $\hat R$ 하한

이론상 $R \le A_h$ 이므로 측정값 기준 하한을 둔다.

$$\boxed{\;R_{\min} = A^{\text{slow}}_h \cdot \rho_R, \qquad \rho_R = 10^{-3}\;}$$

### 승법 상한을 두지 않는 이유 (옛 25배 클램프)

$\hat R_{t+1} = (1-k)\hat R_t + k\min(s_t,\, c\hat R_t)$ 로 두면
$\hat R$ 이 작을 때 순수 승법 재귀가 되어 $\log\hat R$ 이 드리프트 있는
랜덤워크가 된다. $p_0$ = 표본이 정확히 0 일 확률이라 하면

$$\mu = p_0\log(1-k) + (1-p_0)\log\big[(1-k) + kc\big]
\approx k\big[(1-p_0)(c-1) - p_0\big]$$

$$\mu < 0 \iff \boxed{\;c < \frac{1}{1-p_0}\;}$$

이면 $\log\hat R \to -\infty$ 거의 확실하게. 실측 ($s$ = 0 또는 Exp(1)):

| $p_0$ | 임계 $c^* = 1/(1{-}p_0)$ | $c{=}5$ | $c{=}25$ | $c{=}1000$ |
|---|---|---|---|---|
| 0.50 | 2.0 | 0.580 | 0.427 | 0.458 |
| 0.80 | 5.0 | **붕괴** | 0.229 | 0.205 |
| 0.90 | 10.0 | **붕괴** | 0.119 | 0.105 |
| 0.96 | 25.0 | **붕괴** | **붕괴** | 0.044 |
| 0.995 | 200.0 | **붕괴** | **붕괴** | 0.002 |

각 행에서 $c < c^*$ 인 칸만 정확히 붕괴한다.
$c{=}25$ 로 붕괴했다는 건 $p_0 \gtrsim 0.96$ 이라는 뜻이다.

### 중복 스냅샷

호가가 안 바뀌어도 H0STASP0 은 주기적으로 오므로 `ofi_norm` 이 직전 값과
정확히 같아진다. 그 틱을 쓰면 세 점 중 둘이 같아져 2차 차분이
**1차 차분으로 퇴화**한다: $z_1 = z_0$ 이면

$$D = z_0(c_0 + c_1) + c_2 z_2 = h_1(z_2 - z_0)$$

기울기가 그대로 새어 들어온다. 셋 다 같으면 $D = 0$ 이고 0 은 흡수점이다.

| `repeat_mode` | 중복 50% | 중복 96% |
|---|---|---|
| `none` | $\hat q$ 13.4배, $\hat R$ 4.9배 | $\hat q$ **2700배**, nis **1965** |
| `estimator` | 추정 정상, 깨어나는 첫 10초 RMSE 11배 (0.031 → 0.355) | 같음 |
| `skip` | 정상 | 정상 |

`estimator` 는 추정기만 건너뛰고 필터는 먹인다. 게인·level 은 5초에 회복하지만
그 순간이 비싸다:

| 전환 후 | `skip` 오차 | `estimator` 오차 | 배율 |
|---|---|---|---|
| 0초 | 0.0353 | **2.2731** | **64.3** |
| 1초 | 0.0508 | 0.3526 | 7.0 |
| 3초 | 0.0399 | 0.0517 | 1.3 |
| 5초 | 0.0269 | 0.0276 | 1.03 |
| 10초 이후 | 0.0200 | 0.0200 | **1.00** |

**`repeat_frac` 라인을 재서 고를 것.** $\le 50\%$ 면 `estimator`, $\ge 90\%$ 면 `skip`.

### $R$ 레짐 변화의 추적 속도 (한계)

$R$ 이 실제로 5배로 변하면 반감기 1800초의 대가를 치른다:

| 변화 후 | $\hat R/R$ | nis |
|---|---|---|
| 5분 | 0.25 | **3.65** |
| 30분 | 0.48 | 2.08 |
| 60분 | 0.69 | 1.38 |
| 120분 | 0.91 | 1.12 |

**nis 가 경고등 역할을 한다** (3.65 → 1.12). $R$ 이 자주 변하는 종목이면
`var_halflife` 를 600초로 줄인다 — 600초도 정상 범위다 ($\hat R/R$ 1.02, nis 0.987).

## 11. 구현 요약

### 의사코드

```
# ── 초기화 ──
for each lag in (h, 2h):
    tri[lag]      = 삼중항 버퍼 (span = 3h)
    A_fast[lag]   = None;  n_fast[lag] = 0
    A_slow[lag]   = None;  n_slow[lag] = 0
p_tail  = erfc(sqrt(th/2))
c_trunc = 1 - 2*sqrt(th)*phi(sqrt(th)) / (1 - p_tail)

# ── 매 틱 ──
on tick (t, z):
    # ① 중복 스냅샷
    n_total += 1
    is_repeat = (z == last_z)
    if is_repeat:
        n_repeat += 1
        if repeat_mode == "skip":  return 이전 level   # prev_t 갱신 안 함
    last_z = z

    dt = max(t - prev_t, min_dt)
    rate = EMA(1/dt, rate_halflife)                    # 포아송 lambda 용

    # ② 추정
    if not (is_repeat and repeat_mode == "estimator"):
        for lag in (h, 2h):
            tri[lag].push(t, z)
            삼중항 (t0,z0),(t1,z1),(t2,z2) = tri[lag].at(t-lag), ..., (t,z)
            if 간격 h1,h2 가 [lag*tol_lo, lag*tol_hi] 밖:  skip

            c0,c1,c2 = h2, -(h1+h2), h1
            D = c0*z0 + c1*z1 + c2*z2
            W = c0^2 + c1^2 + c2^2
            s = D*D / W

            # fast: 전부 받는다 (q 는 사건을 봐야 한다)
            n_fast[lag] += 1
            k = max(1/n_fast[lag], 1 - exp(-dt_fast/tau_q))
            A_fast[lag] = s*k + A_fast[lag]*(1-k)

            # slow: 게이트 통과만 (R 은 이상치에서 지킨다)
            surprise = s / A_slow[lag]                 # ~ chi2_1
            if surprise > th:
                hit = True
            else:
                hit = False
                n_slow[lag] += 1
                k = max(1/n_slow[lag], 1 - exp(-dt_slow/tau_R))
                A_slow[lag] = (s/c_trunc)*k + A_slow[lag]*(1-k)

        # 과다제외 가드: 최근 창 제외율 > excl_guard 면 강제 수용
        # 포아송: 창 안 발화 수 vs lambda = p_tail * rate * pois_window

        R_hat = max((8*A_slow[h] - A_slow[2h]) / 7,  A_slow[h]*rho_R)
        q_hat = max(9*(A_fast[2h] - A_fast[h]) / (7*h^3),
                    rho_q * 9*R_hat / h^3)
        world_frac = 1 - R_hat / A_slow[h]

    prev_t = t
    if R_hat is None or q_hat is None or n_slow < min_n:  return None

    # ③ 필터
    if level is None:
        level, slope = z, 0;  P00 = P11 = R_hat*1e6;  P01 = 0
        return level

    level += slope * dt
    P00 += 2*dt*P01 + dt*dt*P11 + q_hat*dt^3/3
    P01 += dt*P11                + q_hat*dt^2/2
    P11 +=                         q_hat*dt

    S  = P00 + R_hat
    k0 = P00 / S;  k1 = P01 / S
    v  = z - level
    level += k0*v;  slope += k1*v
    P00 = (1-k0)*P00;  P01 = (1-k0)*P01;  P11 = P11 - k1*P01

    # ④ 진단
    V   = EMA(v*v, var_halflife)
    nis = EMA(v*v/S, nis_halflife)      # 창 키우기 적용
    return level
```

## 12. ★ 아직 실데이터로 검증되지 않은 것 ★

위의 모든 수치는 '가속도가 백색잡음' 모델로 생성한 합성 계열에서 나왔다.
**필터가 가정하는 바로 그 모델이므로 순환논리다.**

### 가장 큰 위험 — 2상태 모델이 `ofi_norm` 에 맞는지 모른다

`ofi_norm` 은 유량÷깊이로 정상(stationary)에 가까울 수 있다.
정상 계열은 $h$ 가 커질 때 $A_h$ 가 **포화**한다(평평해짐).
2상태 모델은 $h^3$ 로 **자란다**. 포화하면 $A_{2h} - A_h \to 0$ 이라
$\hat q$ 가 쪼그라들고, 기울기 상태 자체가 의미를 잃는다.

**▶ 첫 검증: $A_h$ 를 $h^3$ 축에 찍어 직선인지 본다.**

- 직선 → 이 모델이 맞다
- 포화 → 1상태로 내려가야 한다 ($\hat R$ 추정과 서프라이즈 제외는
  모델 차수와 무관하므로 그대로 쓴다)

### 그 외 미해결

| | 내용 |
|---|---|
| 입력 | 종목 간 `obs_var` 597배 격차, 003550 의 `level` ±1.79. `ofi_norm` 분모(1호가 깊이)가 분자(여러 호가를 삼킬 수 있음)와 안 맞는 문제로 추정. **입력이 고장난 채로 필터를 올리는 건 순서가 틀렸다** |
| IC | 한 번도 계산하지 않았다. **필터 품질과 예측력은 별개다** |
| 대조군 | 시간기반 EMA(파라미터 1개)와 IC 를 비교할 것. 못 이기면 이 공학은 낭비다 |
| `dd_lag` | 기본 3.0 은 합성 데이터의 $h^*$. 실데이터로 재서 바꿀 것 |

### 녹음 하루로 할 검증 순서

| 순서 | 볼 것 | 결과에 따라 |
|---|---|---|
| 1 | `repeat_frac` | $\le 50\%$ → `estimator`, $\ge 90\%$ → `skip` |
| 2 | `world_frac` | 0.5 에서 멀면 `dd_lag` 조정 |
| 3 | $A_h$ vs $h^3$ 이 직선인가 | 포화면 1상태로 |
| 4 | `nis` 가 1 근처인가 | 멀면 모델이나 파라미터가 틀림 |
| 5 | `r_surprise` 분포 vs $\chi^2_1$ | 꼬리가 두꺼우면 이상치 있음 |
| 6 | `level` 의 IC vs mid-EMA 의 IC | 못 이기면 신호를 바꿀 것 |

**3번이 가장 중요하다.** 그 한 장이 2상태 모델 전체의 근거이고,
아직 아무도 본 적이 없다.
