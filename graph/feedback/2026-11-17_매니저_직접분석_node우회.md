# 매니저가 node 없이 데이터 분석을 했다

- 날짜: 2026-11-17
- 관련: UC-003 M1, `synthesis/2026-11-17_001_칼만 OFI v0 성능 분석 (2026-10-23 mock 데이터)`

## 일어난 일

1. 사용자가 v0 칼만 OFI의 성능 원인을 분석하라고 했다.
2. 매니저가 세션 임시 폴더에서 DB 조회, 추출, IC 분석을 직접 했다.
3. 매니저가 결과를 `out/`에 쓰려 했다. `guard_write.py`가 막았다.
4. 매니저가 librarian에게 synthesis 저장을 맡겼다.
5. 사용자가 "노드를 안 타고 작업됐어?"라고 물었다.

## 문제

- 훅은 `src/`, `out/` 쓰기만 막는다. 임시 폴더에서 하는 분석과 실행은 막지 않는다.
- 그래서 결과물이 되는 작업이 실행 기록(`index/run/`)과 검증 없이 끝났다.
- 쓰기가 막힌 뒤 위키 synthesis가 우회로가 되었다.

## 제안

- `guard_write.py`가 결과물 쓰기를 막을 때 "node를 만들어 worker에게 맡긴다"를 안내한다. 지금 메시지도 이 뜻이다. 그러나 위키 우회를 막는 말이 없다.
- `/project_manager` 지침에 한 줄을 더한다: "데이터 분석, 계산, 코드 실행이 결과물의 근거가 되면 node로 맡긴다. 토론 자료라도 같다."
