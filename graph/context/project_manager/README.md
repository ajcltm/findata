# context/project_manager/ — /project_manager, /run, /decide, /change에 덧붙일 추가 지침

이 폴더에는 사용자가 **프로젝트 매니저의 일하는 방식 (보고 형식, 소통 방식, 운영 규칙)**을 넣습니다.

- md 파일을 넣으면 프로젝트 매니저가 일할 때 그 내용을 따릅니다.
- 폴더가 비어 있으면 기본 지침만 따릅니다.
- 이 README.md는 안내문입니다. 지침으로 들어가지 않습니다.

예:
- `rules.md`: "보고는 개조식으로 쓴다. 외부 기관은 정식 명칭으로 쓴다."
