## 3. 원인 가설

1. 입력과 모델이 맞지 않는다.
   - `ofi_norm`은 흐름(속도)이다.
   - 2상태 모델(수준, 기울기)은 누적 OFI나 가격 같은 계열에 맞는다.
   - 입력의 자기상관이 0에 가까우면 기울기 상태는 추정할 것이 없다.
2. q̂ 하한이 게인을 고정한다. 고정 게인이 `level` 잡음을 만든다.
   - 코드 주석: `world_frac`이 모든 `h`에서 0이면 하한 문제가 아니다. 그때는 2상태 모델 자체가 맞지 않는다.
   - 이번에는 `h`=3초만 보았다. → [[concepts/칼만 실데이터 검증 순서]]
3. `nis` 꼬리가 두껍다 (중앙값 0.23, 평균 0.82). 이상치 게이트를 없앤 뒤 R̂에 이상치가 섞인다. → [[decisions/칼만 이상치 게이트 제거]]

## 5. 남은 과제

1. 다른 `h`(`dd_lag`)에서 `world_frac`을 점검한다.
   - 모든 `h`에서 `world_frac`이 0이면 가설 1(모델 불일치)을 택한다.
   - 어떤 `h`에서 0보다 크면 가설 2(하한)를 먼저 고친다.
2. 다른 날짜 데이터가 생기면 같은 분석을 반복한다.

## 6. v1 토론 거리

1. 필터 대상 선택:
   - `ofi_norm` + 1상태 또는 AR(1)
   - 누적 OFI + 2상태
   - mid + 2상태, OFI는 보조 입력
2. 목표 보유 기간 선택 (10/30/60/300초 중 하나).
3. v1 합격 기준: IC 하한과 1분당 부호 변경 상한.
