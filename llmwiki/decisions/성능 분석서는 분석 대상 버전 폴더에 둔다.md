# 성능 분석서는 분석 대상 버전 폴더에 둔다

성능 분석서는 분석 대상 버전의 폴더 `out/strategy_design/<버전>/analysis/`에 둔다. 작성하는 사이클의 버전 폴더에 두지 않는다.

## 적용

- v0 칼만 OFI 분석서는 v1 사이클에서 썼다. 분석 대상은 v0이다.
- 그래서 분석서와 재현 스크립트는 `out/strategy_design/v0/analysis/`에 있다. → [[sources/kalman_ofi_prev_analysis]]
- `out/strategy_design/v1/analysis/`는 쓰지 않는다. 폴더를 지웠다.

## 관련 원칙 (CLAUDE.md)

- 사이클 결과물(설계 방향서, 설계서, indicator, strategy)에는 같은 버전 번호를 붙인다.
- node는 버전에 묶지 않는다. 버전은 실행할 때 정한다.
