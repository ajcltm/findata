# 칼만 출력 라인과 진단

[[entities/KalmanTrend]]가 매 틱 내는 라인 10개와 진단 방법이다. 라인 목록은 코드 L491-505를 기준으로 한다.

## 라인 (코드 기준)

| 라인 | 뜻 | 쓰임 |
|---|---|---|
| `level` | 평활된 수준 $\ell$ | 필터 출력 |
| `slope` | 초당 변화율 $s$ | 필터 출력 |
| `lead` | `level + slope × lead_s` | 외삽. 전환점에서 오버슈트한다 |
| `obs_var` | $\hat R$. 이상치를 포함한 전체 분산 | 추정치 |
| `q_hat` | $\hat q$ | 추정치 |
| `world_frac` | 세상비중 $f$ | `dd_lag` 점검 |
| `nis` | $v^2/S$의 지수평균 | 자기진단. 1 근처여야 한다 |
| `nis_raw` | $v^2/S$ 순간값 ($\chi^2_1$, 중앙값 0.455) | 진단 |
| `surprise` | $v^2/\hat V$ | 원문: "전략 신호용" |
| `r_surprise` | $s/A^{\text{slow}}$ | 진단 전용. 게이트로 쓰지 않는다 |

- 워밍업 동안 `level`, `slope`, `lead`, `nis`, `nis_raw`, `surprise`는 `None`이다 (코드 `_blank()`).
- 명세 11장의 `excluded`, `p_window`, `repeat_frac` 라인은 코드에 없다. 중복 비율은 상류 [[entities/BestQuoteFlow]]의 `dup_frac`에서 본다.

## nis — 유일한 자기진단 창 (10장 정리 A)

- $\hat q = q$, $\hat R = R$이면 nis = 1이다.
- $P$의 리카티 재귀에는 $z$가 없다. 원문 10장: "$P$ 는 데이터를 보지 않고 $\hat q, \hat R$ 만으로 굴러가므로 자기가 틀렸다는 걸 구조적으로 알 수 없다."
- $\hat Q = 10^{-2}Q$이면 nis 5.944, $M/P$ 53.0이다 (10장 표).

## 하한에 앉았는지 보는 법 (코드 L441-450)

- `world_frac` ≲ `q_floor_ratio`이고 `nis`가 1보다 뚜렷이 작으면 $\hat q$가 하한에 앉았다.
- 코드 L446-447: "합성 호가창 실측: world_frac 0.000~0.004 에서 q̂/하한 = 1.00, nis 0.67~0.70".
- `world_frac`이 모든 $h$에서 0이면 2상태 모델이 맞지 않는다. → [[concepts/칼만 실데이터 검증 순서]]

## R 레짐 변화 (10장)

- $R$이 5배로 바뀌면 5분 뒤 nis 3.65, 120분 뒤 1.12다.
- $R$이 자주 바뀌는 종목이면 `var_halflife`를 600초로 줄인다.
