# q R 분리 추정

관측 $z$만으로 세상의 변화 세기 $q$와 센서 잡음 분산 $R$을 따로 추정하는 방법이다. 세 점 조합, 두 lag, 두 반감기를 쓴다.

## 1. 세 점 조합 $D$ (3장, 코드 `three_point()`)

- $h_1 = t_1 - t_0$, $h_2 = t_2 - t_1$로 둔다.
- $c_0 = h_2$, $c_1 = -(h_1 + h_2)$, $c_2 = h_1$. $D = \sum c_i z_i$.
- $\sum c_i = 0$이 수준을 지운다. $\sum c_i t_i = 0$이 기울기를 지운다.
- 간격이 달라도 성립한다. 원문 3장: 등간격을 가정하면 "$\hat q$ 가 진짜의 **15.51배**".

> ⚠️ 1차 차분으로 $R$을 재지 않는다. 원문 3장: 2상태에서는 배율이 "7.0배까지 벌어진다".

## 2. 분산 분해 (4장)

- $\text{Var}(D) = qG + RW$, $G = h_1^2h_2^2(h_1+h_2)/3$, $W = \sum c_i^2$.
- 정규화 표본 $s = D^2/W$. $A_h = \mathbb{E}[s] = R + qh^3/9$ (등간격 환산).

## 3. 두 lag으로 분리 (5장)

| 식 | 뜻 |
|---|---|
| $\hat q = 9(A_{2h} - A_h)/(7h^3)$ | $\hat R$이 식에 없다 |
| $\hat R = (8A_h - A_{2h})/7$ | 기댓값이 정확히 $R$이다 |

- lag을 하나만 쓰면 $\hat R$ 과대추정이 $\hat q$를 음수로 만든다. 그러면 필터가 얼어붙는다.
- 원문 5장 실측: "1차 차분 $\hat R$(진짜의 7배)을 넣으면 $\hat q = -2.13\times10^{-3}$".

## 4. 세상비중 $f$와 기준 lag $h^*$ (6장)

- $f = (qh^3/9)/A_h$. 출력 라인 `world_frac` $= 1 - \hat R/A_h$.
- $h^* = (9R/q)^{1/3}$. $f = 0.5$인 lag이다. 합성값 $q = 7.5\times10^{-4}$, $R = 2.0\times10^{-3}$이면 $h^* = 2.88$초.
- 오차 증폭: $\hat q$ 쪽 $1/f$배, $\hat R$ 쪽 $1/(1-f)$배. $f = 0.5$에서 양쪽 2배다.
- 코드 L156: "$h/h^* \in [0.5, 2]$ 면 충분하다". 코드 L185: "조건 하나: h ≥ 평균 틱간격 × 6."

| `world_frac` | 조치 (6장 설정 지침) |
|---|---|
| 0.5 근처 | 그대로 둔다 |
| 0.1 이하 | `dd_lag`를 늘린다 |
| 0.9 이상 | `dd_lag`를 줄인다 |

## 5. 두 반감기 (8장, 코드 L188-268)

| 추정치 | 반감기 | 쓰는 쌍 | 이유 |
|---|---|---|---|
| $\hat q$ | 60초 (`q_halflife`) | $A^{\text{fast}}_h$, $A^{\text{fast}}_{2h}$ | $q$는 변해야 한다 |
| $\hat R$ | 1800초 (`var_halflife`) | $A^{\text{slow}}_h$, $A^{\text{slow}}_{2h}$ | $R$은 상수다 |

- 코드 L234 측정: 분리의 손익은 "q 상수 −0.3%  /  q 점프 +4.2~8.4%".
- 코드 L235-238: $q$가 거의 상수이면 반감기 하나가 더 낫다. 녹음의 `q_hat` 일중 궤적으로 정한다.
- 코드 L247: "빠르게 하려면 반감기를 줄여라. h 가 아니다".

## 6. 창 키우기 EMA (8장, 코드 `_Lag._w`)

- $k = \max(1/n,\; 1 - e^{-\Delta t/\tau})$, $\tau = T/\ln 2$.
- 초반에는 지금까지 받은 표본의 정확한 평균이다. 그 뒤에는 EMA로 바뀐다.
- 원문 8장: 단일표본 시드이면 30분 시점 $\hat R/R$이 "[4.06, −0.01, 3.52]"로 흔들린다.

## 7. 하한 (10장, 코드 L838-854)

- $q_{\min} = \rho_q \cdot 9\hat R/h^3$, $\rho_q = 10^{-2}$ (`q_floor_ratio`).
- $R_{\min} = A^{\text{slow}}_h \cdot \rho_R$, $\rho_R = 10^{-3}$ (`r_floor_ratio`).
- 하한은 측정값에서 만든다. 추정치 자신에서 만들면 승법 래칫이 생긴다.
- 코드 L438: "dd_lag 를 1.0 이하로 내리려면 q_floor_ratio 를 같이 내릴 것."
