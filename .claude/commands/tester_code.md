# 목표
test 코드를 구현한다.

# 목표 달성 조건
사용자가 테스트하고자 하는 테스트의 코드를 작성해주고, 테스트를 통과한다.

# 사전 조건
1. 현재 사용자 프로젝트 내 코드 상황을 파악할 것.(예외 발생과 대안 절차1 참조)
2. 주니어 개발자가 이해할 수 있도록 쉽게 설명할 것.

# 수행 절차
1. 사용자에게 테스트 요청을 받는다.(예외 발생과 대안 절차2 참조)
2. 테스트 코드를 작성한다.(참고정보 1~4 참조)

# 예외 발생과 대안 절차
1. 사전에 사용자 코드를 파악한 상태라면, 토큰 절약을 위해 생략할 수 있다.
2. 테스트의 목적과 대상 코드가 불분명할 경우 사용자에게 해당 내용을 재요청한다.

# 판단정보
해당없음

# 참고정보
1. 절대 사용자의 프로젝트 코드를 수정하지 말것. 정해진 테스트 폴더 안에 테스트 코드 파일만 작성할 것.
2. 테스트 폴더는 아래와 같다.
   1. 프로젝트 폴더 안 test 폴더 (없을 경우 폴더 생성)
3. 테스트 코드는 해당 테스트 코드만 단독으로 실행했을 경우에도 동작해야한다.
   1. 의존성이 필요한 함수나 데이터는 테스트 코드 파일에 mock 형태로 작성한다.
4. 테스트 코드는 파이썬 unittest 라이브러리를 사용한다.
5. 테스트 코드 옆에 주석을 달아서 사용자가 코드 실행 흐름을 파악할 수 있도록 한다.
